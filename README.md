# D&D Support — Нефориций (PWA)

Автономное мобильное приложение для D&D 5e (2014). Содержит персональный лист, заклинания, инвентарь, прокачку и журнал сессий.

## Запуск через GitHub Pages

1. Создайте **публичный** репозиторий `dnd-support` в GitHub. Исходный лист персонажа (без будущих личных заметок) станет доступен всем, кто знает URL.
2. Загрузите **содержимое** этого архива в корень репозитория: `index.html`, `sw.js`, `manifest.webmanifest`, папку `icons` и `README.md`.
3. Откройте **Settings → Pages → Build and deployment → Deploy from a branch**. Выберите `main` и `/(root)`, нажмите **Save**.
4. Дождитесь появления ссылки на `https://<username>.github.io/dnd-support/`.
5. На iPhone откройте сайт в Safari, нажмите «Поделиться» → «На экран Домой» → «Добавить».
6. Запустите установленное приложение хотя бы раз с интернетом, затем проверьте без него.

## Сохранения

Игровые данные хранятся локально на устройстве, в хранилище браузера/веб-приложения. **Периодически экспортируйте JSON-резервную копию через раздел «Журнал» → «Данные»**, особенно перед обновлением или переустановкой. Данные разных браузеров и запусков из файлов могут не переноситься автоматически.

## Обновления

При обновлении измените `CACHE_NAME` в `sw.js` (v1 → v2). После публикации откройте приложение с интернетом.

PWA работает по HTTPS. Для локальной разработки используйте HTTP localhost, а не file://.
